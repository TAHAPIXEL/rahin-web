# راهین (Rahin) — نقشه، کاوش همه مغازه‌ها و مکان‌ها و مسیریاب هوشمند فارسی

**راهین** یک وب‌اپلیکیشن پیشرفته نقشه، کاوشگر اصناف و مغازه‌ها (مشابه نشان، بلد و گوگل مپ) و مسیریاب سخنگوی فارسی است که بر پایه **MapLibre GL JS v5.9.0**، **OpenStreetMap / Overpass / Valhalla / OSRM** و پایگاه داده ابری **Supabase** توسعه یافته است.

- 🌐 **آدرس نسخه عملیاتی (Production):** [https://rahin-web.vercel.app](https://rahin-web.vercel.app)
- 🗄️ **پایگاه داده (Supabase):** جداول `rahin_places`، `rahin_place_reviews` و `rahin_reports` با پشتیبانی از RLS و همگام‌سازی زنده با OpenStreetMap

## قابلیت‌های کلیدی نسخه ۲.۰

1. **رندر صحیح و کامل فونت و متون فارسی روی نقشه:**
   - بارگذاری ماژول شکل‌دهی حروف فارسی/عربی (`@mapbox/mapbox-gl-rtl-text`) با آدرس مطلق برای Web Workerهای Blob در MapLibre GL v5.
   - اولویت‌بندی برچسب‌های فارسی (`name:fa`) در تمامی لایه‌های نقشه و میزبانی محلی فونت `Vazirmatn`.
2. **انتخاب مستقیم هر نقطه یا مکان با کلیک روی نقشه:**
   - پشتیبانی از کلیک عادی روی هر نقطه از نقشه یا آیکون‌های اصناف برای مشاهده آدرس دقیق، مشخصات مکان و مسیریابی فوری.
   - پشتیبانی از حالت انتخاب هدفمند (`Pick Mode`) با نوار راهنمای شناور و نشانگر هدف برای تعیین مبدأ، مقصد، خانه، محل کار یا ثبت مکان جدید.
3. **نشانگر استاندارد و دقیق موقعیت فعلی کاربر (Blue Dot):**
   - نقطه آبی استاندارد ۱۶ پیکسلی با حلقه ضربان و تثبیت موقعیت دقیق (`position: absolute; top: 0; left: 0`) بدون بزرگ‌شدن غیرعادی یا جابه‌جایی هنگام زوم.
   - موقعیت‌یاب دومرحله‌ای (`HighAccuracy` با fallback خودکار به موقعیت‌یاب شبکه و امکان تنظیم دستی موقعیت روی نقشه).
4. **نمایش کامل همه مغازه‌ها، کسب‌وکارها و مکان‌ها روی نقشه + ثبت مکان جدید (مشابه نشان، بلد و گوگل مپ):**
   - دریافت خودکار اصناف، مغازه‌ها، داروخانه‌ها، سوپرمارکت‌ها، نانوایی‌ها، رستوران‌ها، کافه‌ها، پمپ‌بنزین‌ها، بانک‌ها، مراکز درمانی و ایستگاه‌های حمل‌ونقل همگانی در محدوده دید نقشه (`/api/places`).
   - شناسنامه کامل هر مکان شامل نام فارسی و انگلیسی، دسته‌بندی و زیردسته، وضعیت باز بودن و ساعت کاری، شماره تماس مستقیم، آدرس پستی، طبقه/واحد، کد پستی، وب‌سایت، اینستاگرام، امکانات (کارت‌خوان، پارکینگ، ارسال با پیک، شبانه‌روزی، وای‌فای، مناسب ویلچر و...) و بخش ثبت نظر و امتیاز کاربران.
   - فرم جامع **ثبت مکان / مغازه جدید روی نقشه** و **ویرایش اطلاعات مکان** با ذخیره آنی در Supabase و نمایش فوری روی نقشه.
5. **مسیریابی دقیق از روی خیابان‌ها و معابر:**
   - رسم دقیق خط مسیر منطبق بر هندسه خیابان‌ها با ترتیب لایه‌بندی استاندارد (خط اصلی روی لایه حاشیه)، پین‌های مبدأ (`A`) و مقصد (`B`)، مسیرهای جایگزین و راهنمای صوتی گام‌به‌گام فارسی.

## ساختار پروژه

| مسیر | توضیح |
| --- | --- |
| `index.html` | پوسته اصلی اپلیکیشن (RTL، شیت‌های پایین‌کش، نوار انتخاب نقطه، HUD مسیریابی) |
| `css/style.css` | استایل کامل رابط کاربری روشن/تیره |
| `js/app.js` | منطق اصلی: جستجو، اصناف، ثبت مکان، گزارش، مسیریابی و تنظیمات |
| `js/map.js` | موتور MapLibre v5 + لایه‌های POI/هشدار/مسیر و اصلاحات RTL فارسی |
| `js/navigation.js`، `js/voice.js` | هدایت گام‌به‌گام، محاسبه انحراف از مسیر و سخنگوی فارسی مرورگر |
| `js/domain.js`، `js/db.js` | ابزارهای فارسی‌سازی/هندسه و ذخیره‌سازی IndexedDB (کاشی آفلاین، تاریخچه، تنظیمات) |
| `api/*.js` | هندلرهای Serverless مستقل (CommonJS) برای `config`، `health`، `search`، `reverse`، `places`، `route`، `alerts`، `geocode`، `transit`، `traffic`، `docs` |
| `scripts/build.cjs` | فقط برای استقرار بسته‌ای (اختیاری)؛ مسیر پیش‌فرض استقرار، تشخیص خودکار Vercel است |

## اجرا و استقرار

```bash
npm start            # اجرای محلی روی http://localhost:3000
npm run bundle       # ساخت آرشیو rahin-bundle.tar.gz (در صورت نیاز)
```

استقرار روی Vercel به‌صورت Zero-Config انجام می‌شود: فایل‌های ایستا (`.html`, `css`, `js`, `fonts`, `vendor`, `icons`) از ریشه پروژه سرو می‌شوند و هر فایل `api/*.js` به‌عنوان یک Serverless Function با Node.js 22 اجرا می‌شود. متغیرهای محیطی لازم:

- `SUPABASE_URL` و `SUPABASE_ANON_KEY` (اختیاری؛ مقدار پیش‌فرض در کد تعبیه شده است)

## API

مستندات زنده: [`/api/docs`](https://rahin-web.vercel.app/api/docs) — شامل `GET /api/config`, `GET /api/health`, `GET /api/search`, `GET /api/reverse`, `GET|POST /api/places`, `GET|POST /api/route`, `GET|POST /api/alerts`, `GET /api/geocode`, `GET /api/transit` و `GET /api/traffic`.

نکته: در همه اندپوینت‌ها اگر `lat`/`lon` ارسال نشود، مرکز پیش‌فرض تهران (۳۵٫۶۸۹۲، ۵۱٫۳۸۹) استفاده می‌شود و هرگز مختصات (۰,۰) به‌عنوان پیش‌فرض در نظر گرفته نمی‌شود.
